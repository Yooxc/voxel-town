02 마을 상세 평면도

위쪽 = 탐험 통로 방향(−Z), 왼쪽 = 서쪽(−X). 위치는 동일 축척이며 번호 표식은 식별을 위해 확대했습니다.

채집 표시는 생성 가능 범위입니다. 꽃·풀의 실시간 위치와 재생성된 돌 위치는 포함하지 않습니다. 일반 광산 돌은 최초 배치 기준, 다온은 대기 위치 기준입니다. 외곽 언덕은 모델의 명목 크기를 타원으로 단순화했으며 충돌 경계가 아닙니다.
